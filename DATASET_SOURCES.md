# Dataset Sources

This document lists the real-world datasets utilized to train the machine learning models in UzhavarHub. These datasets should be cited in the manuscript's reproducibility and methodology sections.

## 1. Crop Recommendation Dataset
- **Title:** Crop Recommendation Dataset
- **Author:** Atharva Ingle
- **URL:** [https://www.kaggle.com/datasets/atharvaingle/crop-recommendation-dataset](https://www.kaggle.com/datasets/atharvaingle/crop-recommendation-dataset)
- **License:** Database: Open Database, Contents: Database Contents
- **Description:** Precision agriculture dataset containing 2,200 samples of 22 different crop classes with corresponding soil (N, P, K, pH) and environmental (temperature, humidity, rainfall) attributes.

## 2. Demand Forecasting Dataset
- **Title:** Demand Forecasting Dataset
- **Author:** Ramin Huseyn
- **URL:** [https://www.kaggle.com/datasets/raminhuseyn/demand-forecasting-dataset](https://www.kaggle.com/datasets/raminhuseyn/demand-forecasting-dataset)
- **License:** CC0: Public Domain
- **Description:** Dataset capturing retail store and product information over time, including inventory levels, units sold/ordered, pricing, competitor pricing, and weather conditions.

## 3. E-commerce Sales Dataset
- **Title:** E-commerce Sales Dataset
- **Author:** Tassawar Abbas
- **URL:** [https://www.kaggle.com/datasets/abbas829/ecommerce-sales-dataset](https://www.kaggle.com/datasets/abbas829/ecommerce-sales-dataset)
- **License:** CC0: Public Domain
- **Description:** Contains records of e-commerce transactions, including customer information, product categories, prices, quantities, and regions.
